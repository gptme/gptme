  • feat(models): add Gemini 4 Hydrogen (#4881) (84c33356d)

  • feat(shell): promoted foreground jobs adopt their capture into the job spool (#4663 step 3) (#4880) (e08a56792)

  • feat(tui): auto-name conversations and show the name in statusline and terminal title (#4879) (1ad8fe94c)

  • feat(memory): let memory match trigger lessons (–lessons, –lesson-dir) (#4870) (62cce2de5)

  • feat(subagent): retained-worktree slice — explicit GC path for isolated agents (#4859) (8d60c0b3b)

  • feat(models): refresh MiniMax Flash choices and plugin requests (#4452) (8a557055b)

  • feat(watch,subagent): owner-scoped work snapshots and explicit watch expiry (#4835) (3d1838a90)

  • feat(subagent): cross-restart writer lease via flock on subagent-writer.lock (#4853) (66219ecfb)

  • feat(complete): emit structured session-end metadata block (#4830) (707db06da)

  • feat(mcp): show which config layer supplied a server in mcp info (#4849) (e92764fc5)

  • feat(config): add [shell] spool_quota_mb to ProjectConfig (#4857) (d91ed80b7)

  • feat(doctor): probe proxy reachability and OAuth token expiry (#4833) (007c2db1a)

  • feat(subagent): report the latest committed checkpoint on subprocess deadline expiry (#4851) (397c67740)

  • feat(subagent): add yield operation that checkpoints and ends an attempt as blocked_external (#4844) (9416527f1)

  • feat(doctor): detect and repair startup config corruption in gptme-doctor (#4813) (d75f9743b)

  • feat: report CLI and TUI agent lifecycle through OSC 7501 (#4771) (1faa02a23)

  • feat(complete): policy-block budget — stop nudging at N blocks, end session at 2N (#3960) (4bd871604)

  • feat(tauri): write crash-log.jsonl on unexpected sidecar exit (#4821) (0121ddf68)

  • feat(memory): opt-in per-session dedup for memory match (–dedup-session) (#4779) (0e65d18df)

  • feat(lessons): auto-include keyworded memories alongside lessons (#4780) (e426a749f)
